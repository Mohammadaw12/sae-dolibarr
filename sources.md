## Documents du projet

Le cahier des charges fourni dans le cadre de la SAE 5.1 a servi de référence pour :

- la définition du périmètre fonctionnel ;
- l'organisation du projet ;
- l'automatisation de l'installation ;
- l'import des données ;
- la sauvegarde et la restauration ;
- la documentation ;
- le versionnement avec Git.

## Utilisation des sources

Les documentations officielles ont été utilisées pour comprendre :

- l'installation et la configuration de Dolibarr ;
- l'utilisation de l'API REST ;
- la configuration de Docker et Docker Compose ;
- la gestion de la base de données MariaDB.

Les scripts présents dans ce dépôt ont été développés et adaptés spécifiquement pour répondre aux besoins de la SAE.
